# Changelog

## 1.0.0 (2026-10-26)

First release.

- Skill `ekko-design-system`: tokens, rules, components, icons, brand and slides, taken from the Figma file
  "[Ekko UI] - Design System" (302 variables, 88 text styles, 17 effect styles, 64 component sets, 4,567 icons)
  and the Brand Guideline v2.0 pages.
- Code tokens: CSS variables (light/dark), Tailwind v4 theme and Tailwind v3 preset.
- Assets: 13 logo SVGs, 3 K-Wave SVGs, 14 UI icons, a UI starter template and a slide master template (1920×1080).
- Scripts: `export-figma.js` (Figma → tokens.json) and `build_tokens.py` (tokens.json → code + docs).
